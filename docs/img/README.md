# Скриншоты для инструкции

Сюда кладутся два снимка SmartScreen для [../windows-install.md](../windows-install.md):

- `smartscreen-1-warning.png` — окно «Windows защитила ваш компьютер» сразу после
  запуска установщика;
- `smartscreen-2-run-anyway.png` — то же окно после нажатия «Подробнее», с видимой
  кнопкой «Выполнить в любом случае».

Снимать на реальной Windows 11 x64 при первом запуске `.exe`, собранного CI-джобой
`build-win` (`.github/workflows/ci.yml`) — на скриншоте должно быть настоящее имя
файла установщика, иначе завуч не узнает своё окно.
