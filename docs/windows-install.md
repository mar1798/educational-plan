# Установка на Windows 11

Инструкция для завуча — как поставить «Расписание колледжа» на свой компьютер.

## 1. Скачать установщик

Файл называется `Расписание колледжа Setup <версия>.exe`. Скопируйте его на компьютер
(флешка, общая папка) любым способом — интернет для установки не нужен.

## 2. Экран Windows SmartScreen

При первом запуске установщика Windows покажет синее окно
«Windows защитила ваш компьютер»:

## 3. Установка

Мастер установки спросит папку — можно оставить предложенную по умолчанию.
Права администратора **не нужны**: программа ставится в папку текущего
пользователя (`%LOCALAPPDATA%`). После установки на рабочем столе и в меню
«Пуск» появится ярлык «Расписание колледжа».

## 4. Обновление и удаление

- **Обновление**: запустить новый `Setup .exe` поверх старой версии — данные
  (учебные планы, расписание, бэкапы) сохраняются, установщик их не трогает.
- **Удаление**: через «Параметры → Приложения» или ярлык `Uninstall` в папке
  установки. База данных и бэкапы остаются на диске (в `%APPDATA%`) на случай,
  если удаление было случайным — их можно удалить вручную позже.

---

### Для разработчика: что здесь ещё не сделано

Оба скриншота выше — заглушки (`docs/img/smartscreen-*.png` нужно снять на
реальной Windows 11 при первом прогоне установщика, собранного CI-джобой
`build-win`, см. `.github/workflows/ci.yml` и `docs/img/README.md`). Также не
пройдены вручную: обновление поверх старой версии, удаление, и приёмочный прогон
на реальных данных колледжа — это финальные пункты выпуска Windows-версии, их можно
закрыть только на живой Windows-машине вместе с завучем.

Пути с кириллицей и пробелами (риск R2) закрыты автоматически: `tests/db/paths.test.ts`
прогоняет создание БД, миграции, бэкап, копию на флешку и восстановление по такому
пути, и этот же прогон выполняется на `windows-latest` в джобе `build-win`.
